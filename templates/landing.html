Algorithm

One tick, five moves

Every timestep the agent runs a complete Bayesian pipeline — no shortcuts, no heuristics.

01
🌀

Drift

EVE moves with probability q before WALL-E acts. Threat level controls q.

q ∈ {0.05, 0.12, 0.20}
by threat level
02
🔮

Predict

Smear the belief across her possible steps. Mass is conserved exactly.

p′ = (1−q)p + q·Σ p(n)/deg(n)
03
📡

Sense

A scan returns unlabeled detections: EVE plus decoys, shuffled.

s = a·e^(−d/5) + noise
θ = bearing + noise
04
⚖️

Update

Marginalise over decoy assignments, multiply, renormalise.

L(c)=ε+Σⱼ wⱼ·N(θⱼ)·N(sⱼ)
post ∝ prior·L
05
⚡

Act

Pick the best move under the battery reserve rule.

reserve = path(pad) + 2·scan_cost
commit only if slack ≥ 0
v2 Upgrades

Six improvements, all measured

Every switch is independently ablated over 200 held-out seeds with 95% bootstrap confidence intervals.

🧠

Learns EVE's speed

Five belief tracks run at different motion rates q and are re-weighted by how well each predicted the sensor readings. Robust to model mismatch.

Online learning
🎯

Exact decoy handling

Instead of a heuristic, it computes the exact probability each detection is EVE by summing over all possible decoy assignments (up to 120 terms).

Combinatorial
📊

Information-efficient scanning

Monte-Carlo expected information gain per battery unit. Scans where information is cheap, from positions that triangulate naturally.

EIG planning
🔋

Reserve from destination

Before committing to a leg, checks the route home from where the leg ends — not from the current position. Zero battery deaths.

Safety
🗺️

QMDP targeting

Targets the cell minimising expected travel distance Σ p(c)·dist(x→c), not the tallest peak. Handles bimodal beliefs correctly.

Value function
🔍

Particle filter check

400 particles shadow the grid belief. Disagreement triggers likelihood tempering. A safety diagnostic that proved unnecessary — which is itself a result.
